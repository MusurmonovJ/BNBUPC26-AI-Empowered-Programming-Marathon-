# Lethe presentation package

The current website film runs for three minutes and makes two visits to the same fictional life. The six-minute talk and three-minute slide cut use shorter live segments; do not insert the full website film into those slots. Use the current [contest recording guide](../contest-kit.md) for the standalone three-minute submission video.

## PowerPoint versions

`lethe-showcase.pptx` contains the twelve-slide six-minute talk. `lethe-contest-3min.pptx` contains the eight-slide contest cut. Both have editable slide text and the corresponding speech in speaker notes. Use PowerPoint Presenter View to keep the notes off the projector.

The showcase includes click-to-reveal planting captures, a connection explanation, a slow dusk comparison, and relationship names. Click once for each reveal before advancing the slide. The short cut retains the relationship reveal. Audience choices are raised-hand prompts; carry the selected choice into the actual game yourself.

The garden text links open the deployed playable entry in a browser. Verify or change those hyperlinks before presenting. A recording and voting destination are not embedded. Keep your recorded fallback ready separately and add the organizer's real voting link when available. The decks use the same original reference captures described below.

Open `lethe-presentation.html` in Chrome or Edge. It is a twelve slide interactive browser presentation with local images and no external font or script dependency. The showcase route targets six minutes. The **3 min** control selects an eight-slide contest route. Open a slide directly with `#1` through `#12`. Browser printing includes the selected route.

Use `showcase-speech.md` for the six minute talk, `contest-speech.md` for the three minute cut, and `speeches.md` for the 90 second voiceover and audience Q&A. Use `improvement-roadmap.md` alongside Claude's implementation plan.

## Controls

| Key or action | Behavior |
|---|---|
| Arrows or Space | Advance through the selected route |
| Home and End | First and last slide in that route |
| F | Toggle fullscreen |
| H | Hide or reveal presentation controls |
| P | Open a separate speaker window for your private display |
| N | Show notes on the current display; use only in rehearsal |
| G | Open the live garden |
| V | Choose a local recording to play |
| Escape | Close a dialog, recording, or notes; the game has a return button above its frame |
| links | Set the verified game URL and actual contest voting URL |

The speaker window includes the current speech, audience cues, next slide, and elapsed time. Keep it off the projector. It never automatically advances the presentation.

## Audience interaction

Slide 2 asks the audience to privately imagine a memory and select its kind. The final slide returns to that prompt. No one needs to share their memory text.

Slide 6 asks for a raised-hand choice between Grandma Mei's words and the rooftop. Selecting an answer updates the game cue and speaker notes. The presenter then makes that choice in the actual game. The deck does not change the game by itself, collect names, or count votes.

Planting, connection, dusk, and portrait controls reveal real reference captures and explanations. These are presentation illustrations, not a second simulation. Always describe the actual game outcome, especially if the audience preserved the rooftop.

The links dialog can clear the room's choices between presentations. Closing the deck also discards the choices. Only the configured URLs remain in browser storage when available.

## Live game and recording

Set the verified deployed episode URL or local development URL in **links** before presenting. No network request begins until you open the game. If a host blocks embedding, use **open in another tab** above the game. The embedded game unloads when you return to slides so its sound and GPU work stop. Use a separate tab if you need to preserve its session between visits.

Choose your own MP4 or other supported video through **play your recording** or V. It plays locally and does not upload anywhere. Returning to slides pauses the recording. No recording is included in this package.

The vote action appears only after you configure the organizer's actual voting URL. Without it, the final slide retains a spoken invitation and the game link rather than inventing a voting destination.
